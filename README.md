# 🚀 AI Career Agent System

## 📌 Overview

AI Career Agent System is an AI-powered career assistant designed to help job seekers improve their resumes, analyze job descriptions, identify skill gaps, generate professional application emails, and track job applications through an interactive analytics dashboard.

This project combines Natural Language Processing (NLP), Machine Learning concepts, Resume Intelligence, and Career Analytics into a single platform.

---

## ✨ Features

### 📄 Resume Analysis

* Upload resume (PDF)
* Extract resume text automatically
* Analyze resume content

### 🎯 ATS Match Score

* Compare resume against job descriptions
* Calculate ATS compatibility score
* Identify resume-job alignment

### 📈 Skill Gap Analysis

* Detect missing skills required for a role
* Highlight improvement areas
* Provide career insights

### 📧 AI Email Generator

* Generate professional job application emails
* Personalized based on resume analysis
* Works even without external AI APIs using fallback templates

### 💼 Job Recommendations

* Suggest relevant job opportunities
* Role-based recommendations
* Easily expandable to real job APIs

### 📝 Application Tracker

* Save job applications
* Store company, role, status

### ✏️ Status Management

Track application progress:

* Applied
* Shortlisted
* Interview
* Rejected
* Offer

### 📊 Analytics Dashboard

* Total Applications
* Interviews
* Offers
* Rejections
* Status Distribution Charts

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/padmavathi-sana/AI-Career-Agent.git
cd AI-Career-Agent
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
